# DSH Hub 0.2.2

## 新增

- 系统托盘常驻：最小化或关闭窗口时可隐藏到托盘；托盘菜单支持打开窗口、刷新 DSH 和退出。两项行为可在「设置 → 外观」中分别关闭。

## 修复

- 修复插件市场中文输入法搜索：组合输入期间不再重绘搜索框，也不再触发搜索刷新；候选框不会被打断，`compositionend` 后才执行查询。
- 修复新建/编辑套装对话框：在对话框右侧空白区域滚动鼠标滚轮时，弹层不再整体移动；只有内容区滚动。
- 输入框在组合输入结束后恢复焦点和光标位置。
